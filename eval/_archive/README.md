# eval/_archive/ — concluded one-off probes

Investigation probes whose questions are answered (camera-model, egomotion, phantom-move,
walkability/embedding surveys, replay validations, model comparisons, RAM-address finders, …).
Kept for the record; run with `python -m eval._archive.<name>` if ever needed. They import only the
**active** eval modules (in `../`), never each other. The active toolset is in [`../README.md`](../README.md).
