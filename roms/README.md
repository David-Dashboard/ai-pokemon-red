# roms/

Drop your own legally-obtained Pokémon Red ROM here, e.g.:

    roms/PokemonRed.gb

Then run from the project root:

    python play_pokemon.py --rom roms/PokemonRed.gb --brain scripted --steps 50

The path is arbitrary — `--rom` accepts any location. ROMs are copyrighted and
gitignored; none is bundled with this project.
