# Live run #3 — recorded, guarded, clean-start (2026-06-16)

_Companion to `2026-06-15-live-run-02.md`. Run #2 reached Oak's Lab for ~$0.23 but **could not get the
starter** — it flailed through Oak's forced dialog and hallucinated its location. Run #3 tests the
harness-only learning/dialog build (steps 1–3) that came out of that wall._

**TL;DR — the run-#2 wall is broken.** With the per-run `LESSON:` buffer, the disconfirm/surprise
detector, fail-safe dialog auto-advance, and the Gen-1 textbox decoder, the agent **left the house,
crossed Pallet, comprehended Oak's gate, chose SQUIRTLE as its starter, and reached the rival battle**
— for **~$0.33** (40 LLM wakes, budget-capped). It halted **mid-rival-battle** on the budget cap, which
is exactly the right place to stop: **battle-move decisions are the next capability we haven't built.**
Steps 1–3 are validated **live**.

---

## 1. What we were trying to do

Run #2's diagnosis: the agent could *navigate* but couldn't *understand or transact* with a scripted
gate (Oak's dialog), and it hallucinated its location because it never read the on-screen text. We then
built (all harness-only, no aria changes, free): a harness-owned `LESSON:` buffer, a disconfirm/surprise
detector, fail-safe dialog auto-advance, and a pixel-only Gen-1 textbox decoder. Run #3 is the paid
validation:

> Does the agent now **get the starter and leave Pallet** at a low, bounded cost — and **where does it
> break next**?

Constraints honored (the north star): screen-only perception (RAM is a non-leaking oracle), the same
decoupled brain, cheap-by-default (free autopilot + auto-advance + wake-LLM-at-decisions).

## 2. Method

**Clean start (zero accumulated experience, archived first):** `reset_aria_memory.py --yes` archived the
prior memory → `aria_memory_archives/iter-002_2026-06-16.zip` (25 KB), wiped the run-generated experience
(`journal/`, `memstore.db`, `usage.jsonl`, `earlier_today.json`), kept the seed constitution + caches.
aria-app was **stopped → wiped → restarted** so no in-RAM state survived; verified clean (only seed +
caches remained).

**The run (headless, recorded, guarded):**
```
play_pokemon.py --brain hybrid --backend aria --perception --load-state start.state \
    --record runs/run3.mp4 --out runs/run3 --max-llm-calls 40 --stuck-steps 80 --steps 800
```
Active for the first time: dialog **auto-advance** (`advance_on_dialog`), the **textbox decoder**
(`screen_text` → the prompt), the **disconfirm/surprise** detector, and the per-run **`LESSON:`** buffer.

## 4. What worked, and why

- **Dialog auto-advance is the cost win it was meant to be.** **123 dialog frames were advanced for
  free** (press A, no LLM), so the gate that burned run #2's whole budget cost almost nothing here. The
  LLM was woken at the **5 real choices** (examine a ball, choose the starter, the nickname YES/NO) plus
  the battle — not on every text frame.
- **The agent transacted the scripted gate** — the exact thing run #2 could not do. It comprehended
  Oak's sequence, **chose SQUIRTLE**, declined/accepted the nickname, and triggered the rival battle.
- **Semantic grounding works live (pixels → text).** Decoded straight from run-#3 frames:
  `frame 310 → "A?H received / a ?O??RT?E!"` (= *ASH received a SQUIRTLE!*), `frame 370 → "A?H! / ?et?
  check out"`. Uppercase glyphs not yet in the 42-glyph table read as `?` (never a wrong guess); the
  text is still legible and — unlike run #2 — the LLM read **real events** instead of inventing places.
- **Cost stayed bounded and even improved per-token:** prompt caching partly engaged (**96K cached**
  tokens, vs run #2's 0), and the budget cap halted cleanly at 40 wakes (~$0.33). All 73 aria calls ok.

## 5. What broke — the new bottleneck

- **Battle-move decisions.** The run halted **inside the rival battle** (on the budget cap, not a
  crash). We have **no battle policy** yet — choosing FIGHT/move/switch from the battle menu is the next
  capability. This is the frontier run #2 predicted (navigate ✓, transact gates ✓ now, *fight* ✗).
- **Decoder uppercase coverage is partial.** The early-game charset decodes well; uppercase
  S/Q/U/L/G/V/I/… and a few symbols are uncalibrated → `?`. Easily extended by feeding more frames to
  `eval/calibrate_font.py`.
- **Observability gap:** the oracle log does **not** record `screen_text` or the per-run `LESSON:`s, so
  the live *content* of the decoded text and the lessons can't be read back from `oracle.jsonl` (the
  decoder/lessons are validated by tests + offline decode, and the agent's *behavior* — getting the
  starter — is the live proof). Add `screen_text`/lesson logging to the oracle for the next run.

## 6. Conclusions

1. **Run #3 is a clear success on its hypothesis.** The run-#2 wall (couldn't get the starter) is
   **solved on real hardware** — the agent obtains SQUIRTLE and reaches the rival battle for **~$0.33**,
   with the free autopilot + dialog auto-advance doing the cheap work and the LLM woken only at choices.
2. **The harness-only learning/dialog build (steps 1–3) is validated live.** Auto-advance collapsed the
   gate's wake-burst; the textbox decoder grounded the agent in real on-screen text.
3. **The bottleneck moved again, cheaply and on purpose:** from *transacting gates* to **battle
   decisions**. That — plus the credit-gated gating-probe verdict — is the next work.
4. **Process held:** clean-start + archive + guardrails + record + oracle-verified analysis. RAM truth
   (`in_battle`, map ids) and a decoded frame both confirm the starter + battle; the budget cap kept the
   spend bounded and stopped at the honest edge of our current capability.

## 7. Next steps

- **Battle policy** (the new wall): a minimal FIGHT/move selector — likely the same "wake the LLM at the
  battle menu, give it the decoded battle text + options" pattern, with a cheap default.
- **Extend the glyph table** (`calibrate_font.py`) for fuller uppercase, and **log `screen_text` +
  `LESSON:`s to the oracle** so the next run's grounding/learning content is auditable.
- The credit-gated **gating-probe** LLM verdict (means-ends reasoning) and continued play past the rival.
